# Developer feedback

Use GitHub issues for SDK bugs and feature requests. Include your SDK and Python
versions, a minimal bot example, expected behavior, and a redacted error.
Do not post bot tokens, provider keys, private messages, or personal data.

This repository hosts official releases, documentation, and example bot code.
The SDK implementation and Agartha platform are maintained privately by BFO.
Documentation and example improvements are welcome; the SDK license governs
use of official packages. Report security concerns privately through BFO support.
